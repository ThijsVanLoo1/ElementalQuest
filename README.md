# 🧪 Elemental Quest

In Elemental Quest you explore an abandoned mine for valuable ores. Find all chemical elements, create new  substances and use them to activate the elevator to even deeper levels.

What lies beneath the surface?

## 🎮 About the Game

In **Elemental Quest**, you'll:
- **Explore** an abandoned mine filled with valuable ores and hidden treasures
- **Collect** all chemical elements from the periodic table
- **Create** new substances by combining elements
- **Activate** mysterious elevators that lead to deeper, more challenging levels
- **Uncover** the secrets buried beneath the surface

## 🎯 Gameplay Features

- ⚗️ Chemical element discovery and combination system
- 🔧 Crafting mechanics to create powerful substances
- 🛗 Progression through elemental activation of elevators
- 🏆 Challenging puzzles and exploration-based gameplay

## 🛠️ Technology Stack

This project is built using **Unity** with the following languages:

- **C#** - Core game logic and mechanics

## 📦 Repository Structure

- **Assets/** - Game assets including models, textures, and audio
- **Scenes/** - Game levels and scenes
- **Scripts/** - C# game logic and gameplay mechanics
- **Shaders/** - ShaderLab and HLSL shader files for visual effects
